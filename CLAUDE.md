# CLAUDE.md

Notes for coding agents working in this repository.

## Project overview

PicoOCR (the npm package `picoocr`) - text recognition in pure JavaScript: a classical page layout (lib/layout.js) and a
small neural line recognizer (lib/model.js) whose weights are a generated module (lib/models/recognizer.js) - no
runtime dependencies, no network, no files. [DESIGN.md](DESIGN.md) is the design and its measurements; keep it current.

- `lib/` - the package (browser- and Node-safe ES modules, no Node built-ins, 100% test coverage): `index.js` (the API -
  `recognize`, `loadRecognizer`, `pageText`), `layout.js`, `image.js` (the line input - shared exactly with the
  training, `train/src/picoocr_train/image.py`), `model.js` (the network's layers as im2col and a tiled matrix
  product; CTC decoding), `models/recognizer.js` (generated by `picoocr_train.export` - do not edit)
- `train/` - the training, the python-build package `picoocr_train` (`train/src/picoocr_train/__init__.py` documents
  each module); its data in `train/data/` - the recipe `train.json`, the pinned fonts `fonts.json`, and the pinned
  books `books.json`
- `tools/` - `parity.js` (the package against the training's port and PyTorch - make parity), `pagecheck.js` (the
  package reading test pages - `picoocr_train.pages`)
- `downloads/` - gitignored: the pinned fonts and books, fetched by the training

## javascript-build

This is a [javascript-build](https://github.com/craigahobbs/javascript-build#readme) package. Read the javascript-build
skill before running tests, lint, coverage, or changing the Makefile:
[`../javascript-build/SKILL.md`](../javascript-build/SKILL.md) if that file exists, otherwise
[https://raw.githubusercontent.com/craigahobbs/javascript-build/main/SKILL.md](https://raw.githubusercontent.com/craigahobbs/javascript-build/main/SKILL.md).

Local Makefile overrides:

- `ESLINT_ARGS` - also `tools/` (not the generated `lib/models/`)
- `commit` - also runs the training package's gate (`make -C train commit`); `make clean` cleans it too

## python-build (train/)

`train/` is a [python-build](https://github.com/craigahobbs/python-build#readme) package (its unit tests in
`train/src/tests/`): unittest with `-W error`, pylint, and 100% branch coverage. Its tests run on the CPU, fast, with
no network: a tiny recipe and network, Pillow's embedded font (`tests/helpers.py`), and mocks for the downloads.
They need Pillow's Raqm layout, which loads FriBiDi at runtime - on macOS, `brew install fribidi` (otherwise each
render warns that Raqm is unavailable, an error under `-W error`).
Local Makefile overrides: `PYTHON_IMAGES_EXCLUDE` (3.11, 3.15), `PYLINT_ARGS` (a comment above each function, not a
docstring), and `PIP_INSTALL_ARGS` (PyTorch's CPU wheels on Linux).

## Training

`make train` (build/train/run - its log.jsonl and checkpoints), `make train-export` (build/train/recognizer.js and the
parity check), `make train-install` (lib/models/). `--until N` stops a pilot run without changing the schedule.

## Conventions

- Code style: 4-space indent, single-quoted strings and object keys, a short comment above each function and block,
  descriptive names (no one-letter names - `id-length`), lines at most 140 characters
- `lib/image.js` and `picoocr_train/image.py` compute the line input identically - change both, and `make parity`
- Runs must be clean: no warnings in training, tests, or builds - fix them, or silence one with a comment saying why
- Stop a process by its PID (never `pkill -f` with a pattern - it matches the shell running it)
